# Anima · Perceive

单页科研 Demo：五个参考案例、自己的实时实验、字幕旁的当前标签。点击标签看依据，“记录”展开历史，结束后可以回放或导出视频与 JSON。入口：**http://127.0.0.1:4827/**。

## 当前实现（2026-10-08）

| 模块 | 实际作用 |
| --- | --- |
| 千问 Omni Realtime | 连续声音转写，字幕独立更新 |
| Qwen 3.7 Flash | 快速判断当前状态，接收画面、已确认的字幕和本机声音分析结果 |
| Qwen 3.8 Max | 较慢的上下文复核，补充具体依据 |
| EmotiEffLib + OpenFace 3.0 | 本机表情分类、面部动作与视线测量 |
| emotion2vec-plus-large | 本机分析原始声音的情绪类别 |
| Romana WavLM | 本机辅助检测重复、修正、卡顿等言语现象 |
| MediaPipe、Silero VAD | 浏览器找脸、动作跟踪与说话边界 |
| 时间与证据整理 | 人物归属、过期清除、迟到留档、真实到达时间回放 |

Flash / Max 不接收原始声音。它们看到声音模型的结果和转写，不能说成直接听出了语调。所有分类分数和状态判断都是估计，不是经过人群校准的概率。当前只观察一个人，不判断撒谎、人格或身份，不读取长期记忆。

10 个社会状态候选：**赞同、反对、怀疑、表达自信、犹豫、挫败、兴趣、不确定、困惑、压力**。另有 7 种表情、6 种语调候选，明确标作“表情 / 语调”。候选数量不代表准确性全部验证。画面最多同时展示 3 个标签，完整事件保存在记录中。

声音连续传输，画面每 0.5 秒更新；各路推理独立运行。快速结果先显示为待复核，复核补充依据。超过当前状态时限的结果只留档，不重新贴到当下画面。字幕只给新增词加入动画。较长的历史上下文最多保留本次会话 45 秒。

实时实验最长 **10 分钟 / 128 MiB**。结束即停止采集；录制及事件暂存在浏览器内存，刷新会丢失，点击“保存实验”导出。上传分析是单独的离线功能，接受 2 分钟 / 32 MB 以内的视频，先真实转写再做融合；不把离线结果伪装成实时。

首页案例仍为带明确标识的既有离线分析，用来演示交互。实时能力以“试试自己”和研究验证记录为准。

## 使用

需要 Node.js 22.19 以上。这台机器的依赖和模型已安装：

```sh
npm start
```

或双击 `启动 Anima.command`。打开“试试自己 → 模型设置”，填千问 Key；快速判断和复核模型可以分别选择。密钥只保存在本地服务的运行内存，不返回前端，不写入源码；服务重启后重新填写。模型清单不代表账号权限、额度或免费资格，额度不足会明确提示，不自动改变计费设置。

用户点击开始并授权后，声音发送到配置的阿里云转写服务，画面、转写与测量发送到阿里云判断服务。服务器只监听本机。普通实验不自动落盘，研究工具会将已授权的公开素材测试记录保存在 `research/autosaved`。

默认采用云端转写与本机专用模型；本机模型实际使用 1 个 Torch 计算线程。`ANIMA_LOCAL_ASR=1 npm start` 可显式切换 SenseVoice 本地转写：已验证可用，但长句延迟较大，不是推荐实时配置。MiniCPM-o 4.5 曾在本机真实运行，3 秒音画推理约 12 秒，未采用；AffectGPT 尚未部署。

在新机器安装：`npm install`、`npm run setup`、`npm run setup:models`。缺失或加载失败的模块会如实报告，不视为已运行。模型来源见 `THIRD_PARTY.md`。

## 验证与限制

最新证据与未完成项见 [研究状态](research/README.md) 和 `research/iteration-status.json`。速度分开记录：请求耗时、输入窗口结束至收到结果、实际页面显示时间。任何一个都不直接等于从人开始表达至识别完成的全部时间。

用户不要求标签逐项匹配 Interhuman；其五个官网片段只是开发参考，不是独立留出集，也不能拿官网预录时间轴当作 API 延迟。连续公开片段压力测试只验证运行稳定性。没有独立人工标注，不宣称通用准确率或整体能力已经等同 Interhuman。

`npm test` 检查流式协议、字幕、状态过期、模态约束、错误恢复、权限、回放和上传集成。模拟接口测试验证工程行为，不验证模型准确率。旧的 `baseline / text / audio / video` 研究接口保留；历史底座和标签定义可能不同，不能直接当作严格同底座消融实验。

## 接口

- `GET /api/status`：配置状态、当前模型、实际本机运行参数、进程内已报告用量。不返回密钥，也不声称知道账号剩余额度。
- `POST /api/config`：调整服务地址、Key、快速与复核模型；活动实验中拒绝修改。
- `POST /api/analyze`：离线短片分析。`POST /api/evaluate`：研究对照入口。
- WebSocket `/api/realtime`：持续音画输入及 `anima.perceive.v2` 事件。
- WebSocket `/api/events`：只订阅结果，可供机器人使用；不执行动作。

写接口要求同源和本地会话令牌，WebSocket 令牌通过子协议传递。`start/end` 是输入时间，`detectedAt` 是发现时间；回放遵守真实到达顺序。可用 `node research/subscribe.mjs` 查看订阅示例。

此 Demo 复用了原 Anima 与机器人看板的声音特征、浏览器采集及短期状态设计；两个原仓库保留完整，未引入长期身份、人格画像、TTS 或行为执行。

## 给接手同事的完整背景

请先读[仓库根交接 README](../README.md)：包含产品取舍、四步骤边界、Interhuman 对照口径、当前结果、已知问题和优化顺序。此目录是本次优化主线，原 V5 系统保留在仓库的 `v5/`。

### 补充准备言语结构模型

基础 `npm run setup:models` 只准备 OpenFace、EmotiEffLib 和 emotion2vec。要复现当前三路本机观察，还需：

```sh
integrations/.venv/bin/python integrations/setup-speech.py
```

它从已记录的作者权重地址获取 Romana WavLM 模型与配置，分别校验 SHA-256，放入 `integrations/models/romana-disfluency/`。约 94.4M 参数，权重不随 Git 分发。如果 Google Drive 下载返回网页或被限制，校验会明确失败；按 `research/romana-disfluency-evidence.json` 的来源自行获取同一文件，不能用基础 WavLM 权重替代这个任务模型。

SenseVoice 只用于可选本地转写。`ANIMA_LOCAL_ASR=1` 需要完整模型文件位于 `integrations/models/sensevoice/`；当前安装器不自动准备它。不要仅创建空目录就以为已安装。默认云 ASR 不需要它，且实测更适合当前实时预算。

### 准备研究视频

日常首页的五个案例由 `npm run setup` 准备。六个新人物片段和 10 分钟压力测试另行准备：

```sh
integrations/.venv/bin/python -m pip install imageio-ffmpeg==0.6.0
integrations/.venv/bin/python research/setup-media.py
```

脚本读取已冻结的 `research/cremad/neutral-selection.json`，校验六个来源文件并转成 MP4；同时用已有 Yann 公开片段重复生成 602 秒视频。压力测试页面自己每分钟插入 5 秒黑画面和静音，重复片段仅用于压力测试，不能作为自然长时或泛化准确率数据。媒体不随仓库分发。

### 交接时的验证缺口

当前源码完整工程套件为 93 项检查。最新上传人脸归属修补需要在新启动的服务上重新实测。最终候选没有新的完整 600 秒通过记录；旧长测最后因快速模型额度拒绝，验收标志为 false。首页案例仍为旧的离线结果，不能作为当前模型准确性证明。详见根 README 与 `research/iteration-status.json`。
