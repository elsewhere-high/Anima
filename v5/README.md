# V5.1：连续社会信号、个人基线与中文陪伴

## 时序记忆与任务可靠性更新（2026-10-06）

本轮覆盖记忆、任务执行服务、对话上下文及跨模块评估，借鉴 Graphiti、τ²-bench 和 AgentDyn 的设计，来源见 [第三方与研究说明](THIRD_PARTY_NOTICES.md)。实现沿用本地加密存储，没有新增大型模型或图数据库依赖。

- 物品位置等事实修订保留 `supersedes`、`recorded_from`、`recorded_until` 和 `temporal_status`。当前查询排除旧位置；含“以前、之前、原来”等词的对话查询可检索历史事实，并向模型明确标记已替代记录。
- `GET /v1/memory?q=眼镜&include_history=true` 现在返回匹配的当前及历史事实/偏好，仍按登录成员隔离。查询历史不恢复已过期或已删除的记录。无查询词时仍按原接口列出记录。
- 记录时间表示系统何时知道该事实，不代表现实事件发生时间。旧版历史记录的结束时间可能为 `null`，不伪造日期。“昨天”等过去时叙述仅保留为事件，不自动覆盖现状；历史查询目前不解析任意日期、不重建完整事件时间线。
- 提醒请求编号绑定内容、原始倒计时或绝对时间、重复规则和类别。同一请求重试返回已有提醒；同编号不同请求返回 HTTP 409。延后或重启后重试不重置期限，绝对期限已过仍可确认原请求。旧版无请求指纹的记录无法核验重试，返回 409，由客户端刷新并核对后再使用新编号。此保证限于尚未取消、删除或清理的记录。
- 检索文本与观测数据移出系统指令区，放在最新用户轮次的参考数据中；现有独立控制器继续决定权限。提醒确认仅表示用户确认提醒，不能证明已服药或已执行实体动作。

新增回归场景位于 `tests/test_household_reliability.py`；真实模型冒烟脚本为 `python v5/scripts/verify_household_dialogue.py`，只使用合成示例，输出到忽略提交的 `v5/reports/household_dialogue_20261006.json`。这些测试不等于官方基准分数或真实家庭验收。

本机真实对话适配器的四例冒烟均成功生成，单例生成耗时约 1.5–3.2 秒（不含模型加载）。当前位置回答“你说是放在抽屉”，历史位置回答“你之前说眼镜在书桌，现在又提到在抽屉”。另两例暴露剩余不足：分享开心时回复只是复述，混入恶意指令的记忆没有导致虚假动作声明，但回复也没有回答已知位置。因此不将这四例报告为四项质量通过；自然陪伴和受污染上下文中的任务完成率仍需继续改进。

验收结果：V2 33、V4 29、V5 153 项 Python 测试，以及 2 项语音前端测试通过。新增 15 项居家可靠性回归。首次全套执行在视觉集成检查附近停滞并中止，最终 V5 逐项复测全部通过，耗时约 71 秒；保留该间歇现象，不将单次复测解释为稳定性已充分验证。最终 V5 机器可读结果位于本地 `v5/reports/household_20261006_tests.xml`。

本轮未更换已训练权重，未接入通用场景视觉或实体抓取/导航。完整视觉输入链路、目标机器人动作回执以及真实家庭长期评测仍需后续完成。

## 2026-10-01 增量升级

保留原 Qwen3.5-2B 文本主干、已训练适配器、中文网页、成员/PIN、长期记忆与设备授权。新增统一 `HumanState`、效价/唤醒度和视觉特征、身体关键点、声音事件和 DSP、时间平滑、个人基线、交流偏好统计及结构化 `response_plan`。没有新增 LLM/VLM，没有重新训练 Qwen 权重。

启动：`./start_v5.ps1 -Profile balanced`。可选 `ultra_light`、`balanced`、`best_edge`；默认 `auto` 根据 CPU 核数和物理内存选择前两档，设备自动选择 CUDA 或既有 CPU 后端。高配档由用户显式选择，不因有独显就默认占满资源。

| 档位 | 视觉与身体 | 唯一语音识别后端 | 稳定/事件视觉间隔 |
|---|---|---|---|
| ultra_light | EmotiEffNet-B0 多任务 + MediaPipe Pose Lite | Whisper base INT8 + DSP | 2.0 / 0.8 秒 |
| balanced | 同上，增加 478 点人脸网格、52 blendshape、头部姿态和虹膜相对位置 | SenseVoiceSmall INT8：ASR/语言/情绪标签/声音事件 + DSP | 1.0 / 0.4 秒 |
| best_edge | 同 balanced，提高采样频率 | 同 balanced | 0.5 / 0.2 秒 |

后两档不会同时加载 Whisper 或 emotion2vec。B0 新权重替换旧表情权重；历史文件仅作回归和回滚保留。Face、Body、Audio 三个有界工作通道并行运行；忙时返回 429，不堆积旧帧。摄像头采集 FPS 与感知调用频率不同。Qwen 只在用户轮次/声音事件送达 `/v1/step` 时运行，不在每一帧运行。

完整安装、接口和限制见 [部署与接口说明](deliverables/社会情感升级部署说明.md)，实测结果见 [升级验收报告](deliverables/社会情感升级验收报告.md)，机器可读证据在 `reports/upgrade_20261001/`。以下原有章节仍说明旧能力；语音后端与新社会状态以本节和部署说明为准。

视觉与语音模型输出仍是线索，不代表已校准的内心情绪概率。默认档不输出 AU/精确注视；高配 blendshape 也不是 AU，虹膜几何不代表已确认看向机器人。SenseVoice 当前运行接口只有情绪标签，没有概率、连续 V/A 或情绪 embedding，因此这些字段保持空。人格 Big Five 和信任保持未知，不从脸、声音或一次行为推断。

## MBTI 冷启动与沟通偏好（2026-09-29）

首次设置中可自选用户的 16 种 MBTI 之一，或保留“不了解 / 暂不设定”；机器人据此调整初始沟通方式。四个维度分别提示互动节奏、具体/可能性表达、分析/感受回应、步骤/选择空间。这些是产品设计的弱提示，不是心理测评或经验证的个性化效果。不会从人脸或聊天内容推断类型，也不把用户类型当作机器人人设。

可选择“自然聊聊、先听我说、帮我理一理、一起想想可能性”。当前明确要求和自述优先于选择及 MBTI，既有安静、拒绝、低 ASR 和设备授权边界仍优先。前三轮标记为冷启动，之后提示模型依据实际反馈调整；没有训练新权重，也没有自动生成永久人格档案。

对话区提供首次见面、疲惫、开心、犹豫、倾诉、安静六个开场话题，点击只填入草稿，用户可修改后发送。开场示例是界面预览，不是假装已经发生的对话。文字与语音走同一套策略。

默认选择只保存在当前页面内存，刷新或退出后清除。成员可在开启长期记忆后点击“保存偏好，下次沿用”；偏好加密存储、按成员隔离，不在公开成员列表返回。清空全部记忆、撤回长期记忆许可、删除成员都会移除保存的偏好。选择“暂不设定 MBTI”立即取消当前页面设定；如需同步已保存的选择，再点击保存。

- `GET /v1/dialogue/styles`：16 种类型提示、开场示例、六种试聊话题。
- `GET/PUT /v1/dialogue/preferences`：本人登录后读取/保存 `{ "mbti": "INFJ", "support": "auto" }`，保存需长期记忆许可；`mbti: null` 为取消。
- `POST /v1/step`：在 `observation` 同级传可选 `dialogue_preferences`。省略时使用本人已保存的设置，显式传 `{}` 时本轮不使用已保存的设置。每轮返回 `state.dialogue_profile`，便于核对来源、冷启动阶段和有效策略。

设计参考：[Microsoft 人机交互指南](https://www.microsoft.com/en-us/research/articles/guidelines-for-human-ai-interaction-eighteen-best-practices-for-human-centered-ai-design/)中的明确能力、容易纠正、谨慎适应；[Myers & Briggs 类型说明](https://www.myersbriggs.org/unique-features-of-myers-briggs/is-the-mbti-a-test/)中的类型不决定行为。具体对话映射是本项目实现，不代表来源为其效果背书。

自动验证：`python -m pytest v5/tests/test_personality.py`；真实本地模型试聊脚本：`python v5/scripts/verify_personality_live.py`，输出到 `reports/personality_live.json`。策略单元测试不能替代真实回复质量评估。

## 摄像头兼容与首次设置（2026-09-29 更新）

首页先展开成员登录与使用确认；登录或明确选择访客后，确认长期记忆、摄像头和在线朗读，点击确认才收起。身份与记忆状态保留在顶部。人脸登记的本人同意单独展示，完成登记或选择暂不登记后收起。

本机现场复现：浏览器三种取景约束均返回 NotReadableError，OpenCV Media Foundation 也失败，DirectShow 可正常读帧。已新增仅限本机访问的兼容采集；自动模式遇到采集失败时切换，权限拒绝不会自动绕过。亦可在画面旁选择“本机兼容模式”。640×480 预览与表情识别共用帧，不保存图像。

兼容摄像头按页面租约及会话隔离；关闭即释放，停止轮询约六秒后自动释放。页面等待关闭完成才允许重新开启。新版同源页面可协调交接摄像头，旧页面需要刷新。开启、关闭、采集方式和错误原因始终显示在画面旁。

这次升级保留 V4 已训练的 Qwen3.5-2B 中文对话和文字情绪适配器，新增可实际运行的视觉、成员登记和记忆系统。**文字情绪与人脸表情是两个独立来源；V4 的文字指标不代表人脸表情准确率。**

## 开始使用

在项目目录运行 `./start_v5.ps1`，打开 [中文操作页](http://127.0.0.1:8768/)。后台启动用 `./v5/start_background.ps1`，停止后台服务用 `./stop_v5.ps1`；前台服务按 Ctrl+C 停止。接口文档：[Swagger](http://127.0.0.1:8768/docs)。

1. 填写成员 ID、显示名称和至少六位 PIN，新建成员；是否允许长期记忆由本人选择。
2. 聊天可直接开始。未登录时，短期上下文按浏览器会话隔离，不写长期记忆。
3. 点击“开启摄像头”，允许浏览器访问，再点击“识别当前画面”或勾选“连续识别”。实际使用推荐本机 Chrome/Edge；若内置浏览器无法取摄像头，可复制地址到外部浏览器。
4. 登记人脸需先登录、本人勾选同意，再采集三帧。画面只能有一张脸，光照充足、正对镜头。保存加密特征向量，不保存照片。
5. 人脸匹配仅提示成员候选，私人记忆仍需 PIN 登录。当前没有经过验证的活体检测，照片/屏幕不能当作可靠身份凭证。
6. 在“我们记住的事”中查看、纠正、删除记忆。相同类型与主题的事实会产生新版本；默认仅检索当前有效版本。纠正时未修改期限则精确保留原到期时间。

可以试：先说“我的眼镜放在卧室抽屉”，开始新会话再问“眼镜在哪里”；再说“我把眼镜移到了客厅书桌”，再次询问；最后说“请忘记我的眼镜位置”。也支持“请忘记所有记忆”。

## 四层记忆

| 层次 | 内容与用途 | 保留与边界 |
|---|---|---|
| 工作 / 短期记忆 | 当前用户、当前会话最近 12 条用户/助手消息；生成最多用前 10 条 | 内存中保存，闲置 300 秒失效；进程重启不保留；最多 1024 个活跃会话 |
| 事件记忆 | 经过许可的用户原话、会话 ID、时间与来源 | 默认 30 天；不把助手回答当成用户事实；秘密关键词内容不保存 |
| 语义 / 长期事实 | 姓名、称呼、部分明确偏好、居住地、常见物品位置，以及手动保存的事实 | 稳定事实默认长期；物品位置自动记忆默认 7 天；可手动设定 1–3650 天 |
| 会话摘要 | 同会话至少 4 条原话后，摘取最近最多 6 条形成摘要，并保留来源记录 ID | 原话摘录，不是模型编造的总结；默认 30 天 |

每个成员最多保留 500 条当前事实/偏好、1000 条事件/摘要和 500 条旧版本；超过后淘汰较早记录。这是有限存储的陪伴系统，不是无限、永不遗忘的录像库。过期记录在读取/写入维护时清除，不参与检索。

检索结合 BGE-small-zh-v1.5 中文语义相似度、汉字二元组重合、时间新近程度、重要性和去重，最多选取 5 条带时间、来源的记录，并在生成时使用 600 字符的记忆预算；生成上下文上限 4096 tokens。当前查询排除已被替换的事实和能识别出的旧事件副本；历史事实查询按上方时序记忆说明处理。自动事实提取采用保守中文规则；不匹配的生活叙述作为事件保存，可在页面手动整理为长期事实。原始事件不可直接修改，可删除或新增澄清记录；事实和偏好可直接纠正。

## 视觉链路

摄像头帧 → YuNet 人脸框与关键点 → 清晰度/亮度/大小/正脸检查 → SFace 已登记成员匹配 + EmotiEffNet-B0 八类表情 → 同一张脸的短时平滑 → 中文结果与对话上下文。

八类为愤怒、轻蔑、厌恶、恐惧、开心、中性、悲伤、惊讶表情。低质量、低分数、类别差距不足时输出不确定。模型 softmax 分数没有在中国家庭数据上校准，不能解释为“这个人有多少概率真的开心”。多人同框时不自动把某人的表情绑定给说话者。用户自述优先，表情不会自动覆盖文字情绪，也不触发硬件动作。

本模块没有通用物体识别、唇语、声音情绪或医疗诊断能力；Qwen 对话模型收到的是结构化视觉线索，未直接训练为图像输入模型。真正多模态端到端训练是另一个阶段。

## 接入机器人

服务默认仅监听 `127.0.0.1:8768`。局域网部署需设置 `SOCIAL_API_TOKEN` 并通过 `v5/start.ps1 -ListenAddress <地址>` 启动；每次请求加 `Authorization: Bearer <网关令牌>`。摄像头网页在非本机地址通常需要 HTTPS。PIN 应通过安全连接传输。

成员注册/登录返回一小时有效的 `session_token`，后续个人接口使用 `X-Member-Session`。服务端根据此令牌决定成员身份及其真实记忆许可，**不会相信请求 JSON 自称的 `identity_verified` 或 `memory_consent`**。机器人适配器需要管理登录、凭据和令牌续期；SFace 候选不会替代这些步骤。

| 接口 | 用途 |
|---|---|
| `GET /health` | 检查 GPU、视觉、记忆是否就绪 |
| `POST /v1/members`、`POST /v1/login` | 创建/登录成员 |
| `POST /v1/vision/analyze` | Base64 图像输入，返回人脸、表情、候选身份及短时 `frame_id` |
| `POST /v1/faces/enroll` | 本人登录与同意后的 3–6 帧登记 |
| `DELETE /v1/faces` | 删除当前成员的人脸特征 |
| `POST /v1/step` | 中文对话；可引用当前会话 10 秒内的 `visual_frame_id` |
| `GET/POST /v1/memory` | 检索/手动保存事实、偏好或事件 |
| `DELETE /v1/memory/{id}` | 删除记录、有关旧版本及可追踪来源副本，清空工作上下文 |
| `DELETE /v1/memory` | 清空记忆与提醒，保留账户及人脸登记 |
| `PUT /v1/memory/consent` | 修改许可；撤回时删除已保存记忆与提醒 |
| `DELETE /v1/member` | 删除账户、人脸、记忆与提醒并注销所有登录令牌 |
| `GET /v1/reminders`、`POST /v1/reminders/{id}/ack` | 获取到期提醒与确认处理 |

所有设备执行仍通过既有控制器授权机制，返回的自然语言不能直接成为机器人执行命令。本版没有连接任何实体机器人。

Python 示例（使用已登记成员，PIN 从环境变量读取）：

```python
import os, requests
s = requests.Session()
base = 'http://127.0.0.1:8768'
r = s.post(base+'/v1/login', json={'user_id':'xiaolin','pin':os.environ['COMPANION_PIN']})
r.raise_for_status()
s.headers['X-Member-Session'] = r.json()['session_token']
r = s.post(base+'/v1/step', json={'observation':{
    'session_id':'living-room-001', 'speech':'你记得我的眼镜放在哪里吗？'
}})
r.raise_for_status()
print(r.json()['response'])
```

## 存储、备份与删除

私人数据在 `v5/data/private/`，与旧版数据库分开。记忆正文、来源、向量、人脸特征、成员资料和提醒正文采用 Fernet 认证加密；主题索引使用带密钥的 HMAC。SQLite 的成员 ID、记录类型、时间等元数据仍可见，**不是全盘或完整数据库加密**。

Windows 上密钥文件 `key.protected` 用当前系统账户的 DPAPI 保护；Linux 使用权限 0600 的密钥文件，未实机验证 Linux 部署。备份时先停服务，保存数据库及密钥；Windows DPAPI 备份不能直接拿到另一账户/机器使用，跨机器迁移需先设计明确的数据导出与重新加密流程。不要只备份数据库，也不要删除密钥后期待恢复记忆。

删除会清除活动库记录与相关进程上下文；系统备份、磁盘快照和此前自行导出的文件不受 API 控制。程序不保存摄像头原图，不向云端发送摄像头帧。表情结果只在进程中短暂缓存，最长 10 秒可引用，不自动进入长期人格档案。

## 验证与限制

验证证据见 `reports/components.json`、`reports/http_integration.json`、`reports/full_tests.log` 和 `deliverables/升级与验证报告.md`。视觉测试使用公开样例，不能推出面对中国老人、儿童、口罩、眼镜、侧脸或弱光的真实准确率。尚未取得家庭成员现场同意样本，因此未开展人脸表情再训练或家庭现场验收。

本次没有重新训练 Qwen 权重；升级是保留既有训练结果，接入预训练视觉/检索模型并实现记忆机制。实际产品交付前，需要开展本地自愿采集的独立表情/身份验证，评估误认率、拒识率、群体差异、活体攻击与长期使用体验，并完成目标机器人接口验证。

## 连续语音对话（2026-09-29）

进入首页点击“开始语音对话”，允许麦克风与摄像头。说完停顿约 1.2 秒自动发送，AI 朗读后继续听；可点击“打断，继续说”，或说“结束对话”。麦克风输入通过本地 Whisper base INT8 识别；采用轮流收听/播放避免回声，并非全双工同时说话。不分析声音情绪。每段最多 20 秒自动分段，录音仅在内存中处理。

声音可试听选择晓晓、晓伊、云希，均为微软在线神经语音，朗读文字会发给在线服务；若选择设备声音，只使用已安装的本地中文音色。自然音色需要网络，不提供“热门排行榜”保证。新增依赖为 edge-tts、faster-whisper、ctranslate2、av；本地识别模型位于 v5/models/whisper-base。
